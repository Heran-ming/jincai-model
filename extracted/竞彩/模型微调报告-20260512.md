## 二、核心失误分析

### 失误1：那不勒斯主胜 ❌
**问题根源**：
- 赛前锁定欧冠 → 球员心理松懈 → 防守专注度骤降
- 3个丢球全源于防守失误（漏人+送点+补时走神）
- 低赔率1.39掩盖了后防隐患

**数据验证**：主场19场不败金身告破

### 失误2：法马利康客胜 ❌
**问题根源**：
- 保级队主场密集防守 → 客队进攻效率骤降
- 控球率61%+15次射门，但仅4次射正
- 保级队门将发挥超神（8.6分）

**模型盲区**：客队进攻效率参数未根据主队战意打折

### 失误3：热刺分胜负 ❌
**问题根源**：
- 保级积分差仅2分 → 利兹联客场拿1分即可接受
- 热刺排名第17位 → 保级压力下更倾向保守
- 模型低估平局概率

**模型盲区**：`relegation_tension` 参数不足，未考虑积分差

## 三、模型调整内容

### ✅ 调整1：新增「高关注度比赛因子」
**针对问题**：那不勒斯赛前锁定欧冠导致防守松懈

**新增参数**：
```json
"高关注度比赛因子": {
  "pre_match_celebration": 0.12,
  "high_stakes_pressure": 0.08,
  "execution_rule": "当比赛赛前出现夺冠/锁定欧冠等利好消息时，胜率权重下调0.05，防守专注度风险+0.12"
}
```

**预期效果**：降低赛前利好消息的强队胜率权重，增加冷门概率

---

### ✅ 调整2：强化「平局因子」
**针对问题**：热刺vs利兹联保级大战平局概率被低估

**参数变更**：
```json
"平局因子": {
  "relegation_tension": 0.17  // 原0.14，↑21%
}
```

**新增参数**：
```json
"relegation_points_diff": {
  "description": "保级积分差与平局概率正相关（积分差越小，平局概率越高）",
  "diff_0_3": 0.22,   // 积分差0-3分：平局概率最高
  "diff_4_6": 0.16,   // 积分差4-6分：平局概率中等
  "diff_7_plus": 0.10 // 积分差7分以上：平局概率较低
}
```

**预期效果**：保级积分差≤3分时，平局概率权重提升至0.22

---

### ✅ 调整3：新增「客队进攻效率修正」
**针对问题**：法马利康客胜被高估（保级队主场密集防守）

**新增参数**：
```json
"客队进攻效率修正": {
  "relegation_home_team": 0.85,
  "execution_rule": "当主队为保级队时，客队进攻效率参数×0.85"
}
```

**预期效果**：客队进攻效率打折15%，降低客胜预测权重
