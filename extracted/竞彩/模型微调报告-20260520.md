## 🔧 本次调整的参数

### 1. 残阵量化精度提升（新增）

**问题**：弗鲁米嫩塞4名中场核心缺阵的影响被低估

**新增参数**：
```json
"残阵量化精度提升": {
  "core_defender_missing": {
    "one_key_player": 0.22,
    "two_key_players": 0.28,
    "three_plus": 0.35
  },
  "core_midfielder_missing": {
    "one_key_player": 0.20,
    "two_key_players": 0.26,
    "three_plus": 0.32
  },
  "combined_penalty": 0.85
}
```

**调整理由**：
- 之前缺乏精确的残阵量化标准
- 需区分位置（后防>中场>前场）和数量
- 双重缺阵（后防+中场）时额外×0.85叠加效应

---

### 2. 强队客场陷阱识别强化（强化）

**问题**：曼城客战南海岸球队4场不胜的历史数据被忽视

**强化参数**：
```json
"强队客场陷阱识别强化": {
  "strong_team_away_trap": {
    "premier_league_teams": ["曼城", "阿森纳", "利物浦", "热刺", "切尔西"],
    "south_coast_teams": ["伯恩茅斯", "南安普敦", "布莱顿"],
    "historical_fails": 0.15
  },
  "trader_away_risk_signal": {
    "cold_factor_boost": 0.10,
    "execution_rule": "庄家明确提示≥2项时，冷门系数+0.10"
  },
  "derby_derby_factor": {
    "derby_derby": 0.15,
    "execution_rule": "德比战时意外因素+0.15"
  }
}
```

**调整理由**：
- 强队客场不稳是反复出现的规律
- 庄家明确提示时应优先采纳
- 德比战的意外因素需要更高权重

---

### 3. 庄家提示采纳规则强化（新增）

**问题**：庄家多次明确提示风险但未被模型采纳

**新增参数**：
```json
"庄家提示采纳规则强化": {
  "trader_signal_priority": {
    "trigger_count": 2,
    "cold_factor_boost": 0.15,
    "trader_weight_boost": 0.15
  },
  "trader_odds_resonance": {
    "resonance_boost": 0.25,
    "trader_weight_final": 0.75
  }
}
```

**调整理由**：
- 5/19庄家正确提示了曼城、热刺等多场风险
- 当庄家提示≥2项时，庄家权重提升至65%
- 赔率异动+庄家提示共振时，庄家权重提升至75%

---

### 4. 连黑动态调整强化（强化）

**问题**：稳健型11连黑，需更严格的投注控制

**强化参数**：
```json
"连黑动态调整强化": {
  "consecutive_loss_adjustment": {
    "conservative_5_loss": {"bet_limit": 15, "odds_threshold": 2.0},
    "conservative_10_loss": {"bet_limit": 5, "odds_threshold": 2.5, "recommendation": "熔断观察"},
    "conservative_15_loss": {"bet_limit": 0, "recommendation": "暂停推荐"}
  },
  "aggressive_fuse": {
    "fuse_threshold": 5,
    "fuse_bet_limit": 10,
    "release_condition": "模型命中率≥50%时释放"
  }
}
```

**调整理由**：
- 稳健型11连黑需立即降额至5元/注
- 连黑10场触发熔断观察
- 连黑15场暂停推荐，等待模型重新校准
