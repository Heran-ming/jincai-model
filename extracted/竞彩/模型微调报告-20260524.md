### 3️⃣ 盘口加深_双因素判断

**判断逻辑**：
```json
{
  "strong_attack_confirmed": "进攻效率高（近5场场均≥1.8球）→ 正路概率大",
  "rotation_confirmed": "残阵（主力缺阵≥3人）→ 诱上概率大",
  "odds_structure": "让平≈让负赔率（差值<0.10）→ 诱上信号"
}
```

**调整理由**：皇马场盘口从1.25升至1.5，但进攻效率高（4球），让胜打出。需同时满足基本面残阵+赔率结构诱上两个条件才反向。

---

### 4️⃣ 保级战_战术分析

**战术分析规则**：
```json
{
  "last_3_rounds_relegation": "保级压力可能导致保守→优先考虑小分/平局",
  "direct_battle": "直接保级大战→平局概率+0.10",
  "home_advantage_limited": "主场优势被压力抵消→权重×0.80"
}
```

**调整理由**：西班牙人保级战预测主胜，实际1-1平局。保级压力有时转化为保守战术而非进攻动力。
