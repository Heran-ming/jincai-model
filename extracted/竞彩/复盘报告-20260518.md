## 🎯 优化建议

### 何时优先使用庄家思维

1. **赔率<1.25的"稳胆"**：庄家一致性过强=诱上信号
2. **赛季末无欲无求队**：情绪变量难以量化
3. **盘口与基本面矛盾**：让球偏深/偏浅
4. **冷门赔率≥2.5**：值得冒险

### 何时优先使用模型预测

1. **德比战/关键战**：战意权重有效
2. **保级队vs强队**：保级战意>盘口信号
3. **赔率区间2.0-3.0**：信息噪声少
4. **杯赛/决赛**：战意权重40%

### 模型参数调整建议

```
建议新增参数：
1. "稳胆风险因子"：当主胜赔率<1.25时，冷门概率×1.3
2. "赛季末诱上识别"：赔率持续降水>0.04时，警惕庄家出货
3. "角色球员爆发系数"：无欲队角色球员超常发挥概率+0.15
```
