## 一、复盘失误分析

### 核心失误场次：门兴 VS 霍芬海姆

| 维度 | 预测 | 实际结果 | 问题 |
|------|------|----------|------|
| 模型预测 | 霍芬海姆客胜50% | 门兴**4-0**大胜 | ❌ |
| 庄家视角 | 客胜1.50赔率看似合理 | 客队惨败 | ⚠️ |
| 失误根因 | 低估无欲队谢幕战荣誉感 + 红牌崩盘 | | |

### 失误原因归类

1. **权重问题**（主要）：
   - 赛季末"无欲无求"队的主场谢幕战荣誉感**权重缺失**
   - 门兴主场赛季最后一战，球员情绪爆发超常发挥
   - 模型未识别此类场景

2. **数据问题**（次要）：
   - 霍芬海姆红牌（伦佩尔两黄变一红）**无法预测**
   - 但情绪失控风险应有概率评估

3. **特殊因素**：
   - 赛季末关键战情绪波动大
   - 谢幕战/告别赛特殊氛围

## 二、本次调整参数

### 1️⃣ 新增：赛季末主场谢幕战荣誉感因子

```json
"赛季末主场谢幕战荣誉感因子": {
  "base_multiplier": 1.15,        // 基础加成
  "last_home_match": 1.25,        // 赛季最后一个主场
  "farewell_player_count": {
    "1_2_players": 1.10,         // 1-2名告别球员
    "3_plus_players": 1.20,       // 3名以上告别球员
    "captain_farewell": 1.25      // 队长告别
  },
  "execution_rule": "当球队：1)已确定无欲无求 2)本场为主场 3)为本赛季最后一个主场 → 主队胜率权重×1.15-1.25"
}
```

**调整理由**：门兴作为"无欲队"，赛季最后一个主场球员荣誉感爆发，导致模型预测偏差

### 2️⃣ 新增：情绪失控红牌风险参数

```json
"情绪失控红牌风险参数": {
  "base_risk": 0.08,             // 基础风险
  "aggressive_teams": {
    "high_aggro": 0.18,          // 高凶悍球队
    "medium_aggro": 0.12,
    "low_aggro": 0.06
  },
  "match_context": {
    "season_finale": 0.15,        // 赛季收官战
    "relegation_battle": 0.13,    // 保级战
    "farewell_match": 0.12,       // 告别战
    "cup_finale": 0.10            // 杯赛决赛
  },
  "red_card_impact": {
    "early_red_card": 0.35,      // 早红牌影响最大
    "mid_red_card": 0.25,
    "late_red_card": 0.15,
    "same_team": 0.80             // 同一球队红牌
  },
  "execution_rule": "赛季末关键战评估时考虑：球队风格×1.5 + 比赛重要性 → 弱势方胜率权重+0.05-0.15"
}
```

**调整理由**：霍芬海姆红牌导致崩盘，情绪失控风险在赛季末关键战显著上升

## 五、执行规则更新

### 新增执行规则
```
当检测到以下场景时：
1. 主队已确定无欲无求（排名10-18位，积分差>10分）
2. 本场为赛季最后一个主场
3. 球队有告别球员

→ 主队胜率权重 × 1.15~1.25
→ 对手（客队）胜率权重 × 0.85

当检测到赛季末关键战时：
→ 情绪失控风险参数 + 0.05~0.15
→ 弱势方胜率权重 + 0.05~0.10
```
