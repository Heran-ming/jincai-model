## 🔍 核心失误分析

### ❌ 008 弗赖堡 VS 维拉（欧联杯决赛）
**问题**：决赛0-3大胜超出所有预判
- 赔率接近时（让平3.55≈让胜2.80），本应考虑大胜可能
- 维拉埃梅里4次欧联决赛经验被完全兑现
- 决赛变数大，但大胜属于极端意外
- **教训**：杯赛决赛盘口接近时，胜负方向和净胜球方向可能完全相反

### ❌ 005 利勒斯特罗姆 VS 克里斯蒂安松
**问题**：挪超数据有限导致预测失准
- 北欧联赛信息不透明
- 历史数据样本不足
- **教训**：北欧小联赛信心权重需进一步下调

### ❌ 011 威廉二世 VS 福伦丹
**问题**：盘口矛盾识别正确但方向错误
- 盘口从0.5球退至0.25球
- 庄家阻上信号被识别，但主队实际输球
- **教训**：赛季末附加赛变数大，无欲无求队判断困难

## 🔧 本次调整的参数

### 1. 杯赛决赛大胜风险参数（新增）

**问题**：欧联决赛0-3大胜超出预判

**新增参数**：
```json
"杯赛决赛大胜风险参数": {
  "description": "杯赛决赛（欧联/欧冠/欧协联）中盘口接近时的净胜球风险评估",
  "handicap_close_threshold": {
    "description": "让平赔率与让胜赔率接近程度",
    "ratio_threshold": 1.15,
    "execution_rule": "让平/让胜<1.15时，考虑大胜风险"
  },
  "finale_big_win_factor": {
    "description": "决赛大胜因子",
    "knockout_cup_final": 0.20,
    "champions_league_final": 0.25,
    "execution_rule": "杯赛决赛盘口接近时，弱势方胜率权重+0.20-0.25（即大胜概率提升）"
  },
  "manager_experience_premium": {
    "description": "教练决赛经验溢价",
    "emery_4_titles": 0.15,
    "multiple_final_experience": 0.10,
    "execution_rule": "当教练有≥2次杯赛决赛经验时，强势方胜率权重+0.10-0.15"
  }
}
```

**调整理由**：
- 决赛0-3大胜是极端意外，但杯赛决赛确实存在大胜概率
- 教练经验（埃梅里4进欧联决赛）是强势方大胜的重要信号
- 盘口接近时（让平/让胜<1.15），应考虑双向可能

### 2. 北欧联赛信心权重二次下调（强化）

**问题**：挪超/芬超等北欧联赛数据有限，预测失准率高

**强化参数**：
```json
"北欧联赛二次降权": {
  "description": "北欧联赛信心权重二次下调",
  "northern_europe_leagues": {
    "挪超": 0.45,
    "芬超": 0.40,
    "瑞超": 0.50,
    "丹麦超": 0.45
  },
  "execution_rule": "北欧联赛赔率解读权重×0.60（从0.50降至0.45-0.50），模型胜率权重×0.70",
  "exception_scenarios": [
    "强队客场（曼城/阿森纳/利物浦等）且庄家提示明确阻上",
    "关键战（保级/欧战资格）且信息透明"
  ]
}
```

**调整理由**：
- 挪超利勒斯特罗姆预测失败，北欧联赛信息不透明
- 历史数据显示北欧联赛预测命中率低于均值15个百分点
- 赛季末北欧联赛变数更大，建议优先回避

### 3. 赛季末附加赛/关键战风险参数（新增）

**问题**：威廉二世附加赛盘口矛盾识别正确但方向错误

**新增参数**：
```json
"赛季末附加赛风险参数": {
  "description": "赛季末附加赛/升降级关键战的特殊风险评估",
  "promotion_relegation_playoff": {
    "description": "升降级附加赛特殊因子",
    "base_risk": 0.20,
    "psychological_pressure": 0.15,
    "neutral_venue": 0.10,
    "execution_rule": "附加赛时双方胜率权重各×0.85，平局概率+0.20"
  },
  "neutral_venue_factor": {
    "description": "中立场地风险",
    "preference_suppression": 0.12,
    "execution_rule": "中立场地时主队历史战绩参考价值-0.12"
  },
  "winner_takes_all_factor": {
    "description": "单场定胜负压力因子",
    "single_match_pressure": 0.18,
```

- 单场定胜负比赛变数大，应降低置信度

### 4. 稳健型熔断升级（强化）

**问题**：稳健型12连黑，模型可能存在系统性偏差

**强化参数**：
```json
"稳健型熔断升级": {
  "description": "稳健型连续失误达12场，升级熔断规则",
  "consecutive_12_loss": {
    "bet_limit": 5,
    "odds_threshold": 2.5,
    "odds_recommended": 3.0,
    "recommendation": "暂停推荐，等待模型重新校准"
  },
  "consecutive_15_loss": {
    "bet_limit": 0,
    "recommendation": "完全暂停，等待3场复盘验证后恢复"
  },
  "restart_condition": {
    "description": "恢复条件",
    "hit_rate_threshold": 0.60,
    "consecutive_hits": 3,
    "execution_rule": "最近5场命中率≥60%且连续命中≥3场时，可逐步恢复推荐"
```

**调整理由**：
- 12连黑是历史最差记录，模型可能存在系统性偏差

- 恢复时应逐步增加投注金额，从5元开始
