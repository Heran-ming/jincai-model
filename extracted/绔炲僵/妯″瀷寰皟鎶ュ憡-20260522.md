## 🔍 失误原因深度分析

### 1. 006场（阿贾克斯）：赔率倒挂信号误判

**问题描述**：
- 让负赔率1.82 < 让胜赔率1.75（倒挂）
- 模型直接判定为"机构不信任主胜大胜"，推荐让负
- 实际赛果：阿贾克斯2-0让胜

**根本原因**：
- 赔率倒挂≠真实信号，可能是机构防范平局
- 阿贾克斯无欲无求，格罗宁根客场战斗力有限
- 双方均无强烈战意时，机构倾向防范平局而非制造冷门

**教训**：
- 附加赛/杯赛中，赔率结构≠正常联赛逻辑
- 战意变量扭曲赔率时，庄家信号失效概率大幅上升

### 2. 005场（佩纳罗尔）：投注方向错误

**问题描述**：
- 庄家判断：盘口主动退让引导主队→客胜被低估
- 实际赛果：佩纳罗尔2-0主胜

**根本原因**：
- 科林蒂安虽然锁定头名，但依然派出半数主力
- 南美杯赛/解放者杯的战意变量比预期复杂
- 盘口退让是引导资金，但主队实际战意更强

**教训**：
- 锁定头名≠真正轮换，需核实出场阵容
- 南美赛事庄家信号可靠性低于欧洲赛事

### 3. 003场（吉达联合）：完美命中但未单独重注

**表现**：
- 盘口0.75→0.25是近一个月最明显矛盾信号
- 庄家视角完美预判

**问题**：
- 庄家冷门三串一仅中1场，003场的完美判断被其他两场拖累
- 冷门串的赔率阈值设置不合理（当前5倍）

## ⚙️ 本次调整的参数

### 调整1：赔率倒挂识别精细化

**文件位置**：模型参数.json → `赛季末附加赛风险参数`

**当前问题**：
- 当让负赔率<让胜赔率时，直接判定为冷门信号
- 未区分"防范平局"和"真实看低主胜"

**调整方案**：
```json
"赔率倒挂识别精细化": {
  "description": "5/22复盘教训：006场让负<让胜是防范平局而非真实信号",
  "odds_inversion_threshold": 0.10,
  "execution_rule": "当让负/让胜赔率差<0.10时，首先检查防范平局可能性，再判断冷门信号",
  "exclusion_check": [
    "附加赛/杯赛场景→平局优先排除",
    "主队无欲无求但客队也无战意→平局概率+0.15",
    "赔率差>0.15时→才考虑真正的冷门信号"
  ],
  "handicap_odds_boost": {
    "description": "赔率倒挂时平局因子调整",
    "playoff_cup": 0.25,
    "normal_league": 0.15,
    "execution_rule": "附加赛/杯赛赔率倒挂时，平局因子+0.25（原0.15）"
  }
}
```
