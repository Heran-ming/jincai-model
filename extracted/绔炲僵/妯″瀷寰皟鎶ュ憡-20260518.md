**模型版本**：v1.7.3 → **v1.7.4**

## 📊 复盘失误根因分析

### ❌ 核心失误场次：尤文图斯 0-2 佛罗伦萨

| 维度 | 模型预测 | 实际结果 | 问题诊断 |
|------|----------|----------|----------|
| 胜负预测 | 尤文主胜 | 尤文0-2负 | ❌ 完全看反 |
| 赔率走势 | 降水=主队强势 | 降水=诱上信号 | ❌ 信号误判 |
| 信心评级 | ★★★★★ | — | ❌ 最高信心最大失误 |

### 根因定位

1. **权重失衡（主因）**
   - 战意权重过高（0.27）→ 忽视赔率异常
   - 赔率<1.25时模型默认"稳胆"，忽视诱上风险

2. **庄家信号识别缺失**
   - 赔率持续降水0.04+ → 庄家在"吸筹"
   - 市场一致性>90%押注主胜 → 庄家出货信号

3. **赛季末情绪变量**
   - 佛罗伦萨无欲无求但荣誉感爆发
   - 角色球员超常发挥难以量化

## 🔧 本次调整内容（v1.7.4）

### 调整1：新增"稳胆诱上识别"因子

**问题背景**：
- 尤文赔率1.21，赔率持续降水→庄家诱上
- 模型未识别此信号，默认"稳胆"押注

**调整方案**：
```json
{
  "稳胆诱上识别": {
    "description": "赔率<1.25时，赔率持续降水是庄家诱上信号",
    "odds_threshold": 1.25,
    "water_drop_trigger": 0.03,
    "upset_multiplier": 1.30,
    "execution_rule": "当主胜赔率<1.25且赛前24小时内降水>0.03时，冷门概率×1.30，胜率权重×0.80"
  }
}
```

**理由**：
- 赔率<1.25时市场一致性极强（>90%押注）
- 庄家通过降水引导筹码流向主胜
- 反向选项（冷门）赔率≥2.5时值得考虑

---

### 调整2：强化庄家视角在"稳胆"场景的权重

**问题背景**：
- 庄家视角正确预判佛罗伦萨客胜@10.00
- 模型预测尤文主胜完全看反

**调整方案**：
```json
{
  "庄家视角_稳胆场景": {
    "description": "赔率<1.25时，庄家视角权重提升",
    "trader_weight_boost": 0.70,
    "normal_trader_weight": 0.50,
    "trigger_condition": "主胜赔率<1.25",
    "execution_rule": "赔率<1.25时，庄家视角权重从50%提升至70%，模型权重降至30%"
  }
}
```

**理由**：
- 庄家信号在"稳胆"场景准确率更高
- 尤文案例证明：庄家视角完胜模型预测
- 权重调整循序渐进（50%→70%，而非直接切换）

---

### 调整3：新增"赛季末强队过热"场景识别

**问题背景**：
- 赛季末强队（欧冠资格）赔率持续被压缩
- 庄家利用市场对强队的信任引导筹码

**调整方案**：
```json
{
  "赛季末强队过热识别": {
    "description": "赛季末强队赔率被过度压缩时，警惕冷门",
    "trigger_conditions": [
      "联赛最后5轮",
      "强队赔率<1.30",
      "对手无欲无求（积分差>10分）"
    ],
    "upset_boost": 0.25,
    "execution_rule": "同时满足上述3个条件时，弱队胜率权重+0.25，冷门系数+0.20"
  }
}
```

**理由**：
- 尤文vs佛罗伦萨：尤文欧冠资格战意，但佛罗伦萨无欲无求仍赢球
- 赛季末强队压力过大，反而失误增多
- 赔率被过度压缩时，市场过于一致→反向机会

---

### 调整4：赔率熔断阈值强化

**问题背景**：
- 尤文赔率1.21，模型推荐主胜→完全看反
- 赔率<1.25时风险收益比极差

**调整方案**：
```json
{
  "odds_execution_fuse": {
    "strong_upset_fuse": {
      "description": "赔率<1.25的强队，需满足庄家视角无阻上信号才可推荐",
      "odds_threshold": 1.25,
      "trader_signal_check": true,
      "if_trader_against": "跳过该选项，不降低赔率凑单"
    }
  }
}
```

**理由**：
- 赔率<1.25时，即使模型看好，庄家视角反对则跳过
- 避免"稳胆陷阱"→防止全军覆没
- 硬性规则：庄家视角与模型矛盾时，优先相信庄家
