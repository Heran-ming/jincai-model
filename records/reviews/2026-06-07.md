## 5. 错误归因与过拟合检查

### 5.1 213场赔率误读

| 错误类型 | 说明 |
|---------|------|
| 赔率信号误读 | 让球胜赔率双降被视为真实强化，但缺乏外部验证。友谊赛场景下，让球胜下降更多是散户过热所致，而非庄家真实信心。 |
| 战意/首发缺误 | 无法获取首发信息的情况下，仍以主力作战模型计算穿盘概率，严重高估。1-0的比分符合“热身轮换、走个过场”的典型友谊赛剧本。 |
| 让球门槛误 | 让2球胜要求净胜≥3球，但友谊赛通常是走流程，主队收着踢。模型未包含“友谊赛强队大胜概率×0.5”的惩罚因子。 |

**过拟合风险**：中。该错误是典型的“赔率信号被误读为庄家信心”，而在数据不足时模型本应完全跳过。需要强化“数据不足时观察绿灯也跳过”的纪律。

### 5.2 数据缺口引发的普遍误判风险

- 全天的亚盘、百家欧赔、凯利、首发全部缺失。
- 在无外部确认的情况下，2场观察绿灯均暴露于未知风险（至少213已证实失误）。
- 赛前锁版已注明空仓理由，但模拟池仍进入了2场。规则允许在数据不足时进入观察绿灯，但213教训显示，友谊赛场景的“缺首发”高度致命，应自动纳入惩罚≥8的红色区域。

### 6.2 新增：友谊赛缺失首发时的强制惩罚参数

```
触发条件：国际友谊赛 + 首发信息无法获取
调整：不确定性惩罚 +3（即base惩罚6→9）
      价值分上限自动设为4（即不可为6或7）
```

### 6.3 修正：让球胜赔率下降信号在友谊赛场景的可信度衰减

```
原规则：让球胜赔率跨窗口下降 → 正向信号
修正：友谊赛场景下，让球胜下降的可信度 ×0.60
      若降幅<0.10（即<5%的盘率）则忽略
```
