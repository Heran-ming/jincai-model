# 竞彩模型

这是竞彩模型的长期资料库，用于保存赛前锁版、赔率复查、赛后复盘、模型参数和滚动统计。

## 核心文件

- `竞彩模型防过拟合与低置信执行规则.md`：执行规则与风控约束。
- `竞彩模型赛前锁版与复盘账本.csv`：赛前锁版与复盘账本。
- `records/portfolio_status.md`：每日更新的持仓与收益率看板。
- `records/dataset/`：结构化观察样本，用于遮盖验证、命中率和 1u 模拟收益统计。
- `extracted/竞彩/`：历史预测、复盘、微调报告和模型数据。

## 自动化约定

- 11:30 任务输出当天初始方案到 `records/1130_initial/YYYY-MM-DD.md`。
- 17:00 任务输出当天复查方案到 `records/17_check/YYYY-MM-DD.md`。
- 21:05 任务读取当天初始/复查方案，并输出最终方案到 `records/21_final/YYYY-MM-DD.md`。
- 21:05 任务同时刷新 `records/portfolio_status.md`，用于查看当前持仓。
- 每日复盘任务读取预测、赛果和账本，输出复盘到 `records/reviews/YYYY-MM-DD.md`，并刷新 `records/portfolio_status.md` 的收益率。
- 盲测回放写入 `records/blind_tests/YYYY-MM-DD-blind-replay.md`，用于隐藏赛果后验证模型和流程。

所有自动化都应优先读取本仓库内的规则、账本、历史记录和参数文件；无法可靠获取最新数据时必须明说，不补造数据。

## 赛前数据源

- 竞彩网受注赛程用于核验官方赛程入口。
- 17500 分别抓取胜平负、让球胜平负、半全场和比分；总进球仅作辅助背景，不作为预测主项；仅开让球的比赛也必须进入锁版。
- 500彩票网综合指数、足彩网赔率中心、澳客、7M、新球体育和500彩票网即时比分用于补充欧赔、亚盘、大小球、凯利、必发与赛果。
- JavaScript 渲染页面无法被 runner 稳定读取时，使用 Tavily 或 Brave Search 摘要补充，并在报告中明确数据缺口。
- 历史相似盘口观察只使用赛前快照，亚盘、半全场、欧赔和竞彩玩法分栏积累；样本不足时只报告缺口，不混入滚球盘口或补造概率。
- 每次赛前自动化都会运行 `scripts/collect_500_snapshots.py`，将 500 彩票网竞彩列表及逐场亚盘、让球指数、亚洲大小球、欧赔公司行写入 `records/odds_snapshots/`。500 比赛 ID 必须结合队名与开赛时间核验后才能映射到竞彩周编号。
- 每次快照采集后会同步刷新 `records/odds_store/`：原始快照仍保留，结构化行和方向摘要用于比较 11:30、17:00、21:05 的赔率/盘口共振。
- 11:30、17:00、21:05 三个赛前报告都会输出独立的“半全场变化与预测”栏目：11:30 建立基线，17:00 比较 11:30 与当前窗口，21:05 比较三个窗口并标记临场反转。大小球不再作为预测主项输出。
- 执行绿灯不强制等待确认首发。首发不可见只作为不确定性惩罚和推翻条件；执行绿仍需赔率方向、盘口支撑和至少一类可靠外部确认，例如亚盘、半全场、凯利、跨源欧赔、伤停、战意或历史相似盘口有效样本。

## 可进入预测的盘口市场

- 全场让球、半全场、半场让球可以进入预测观察池；全场大小球、半场大小球仅作为辅助背景，不进入黄绿灯主计算。
- 三类主市场必须分开锁版，分别记录来源、盘口、赔率/水位、命中条件、三分、最大反方证据和推翻条件。
- 半场盘口只验上半场比分，全场盘口只验 90 分钟常规时间比分；半全场验上半场结果+全场结果；复盘时分市场统计命中率和 1u 模拟收益。
- 赛前无法可靠获取的盘口必须写明缺口，不得用其他盘口反推或补造。
