# 模型资料库

这是模型长期资料库。当前分为两个互相独立的模型域：

- `竞彩模型`：用于保存赛前锁版、赔率复查、赛后复盘、模型参数和滚动统计。
- `投资模型`：用于保存 Signal Arena / 策场与银狐 A股的投资模型、盯盘规则、仓位规则和复盘记录。

两个模型不要混写。竞彩只处理赛事预测，投资只处理虚拟股票交易和市场盯盘。

## 核心文件

- `竞彩模型防过拟合与低置信执行规则.md`：执行规则与风控约束。
- `竞彩模型赛前锁版与复盘账本.csv`：赛前锁版与复盘账本。
- `extracted/竞彩/`：历史预测、复盘、微调报告和模型数据。
- `投资模型/README.md`：投资模型总览。
- `投资模型/策场冲榜模型v2.md`：Signal Arena 策场冲排名模型。
- `投资模型/银狐A股激进模型v2.md`：A股激进短线模型。
- `投资模型/投资模型执行与盯盘规则.md`：自动盯盘窗口、交易触发和记录规则。

## 竞彩自动化约定

- 17 点任务输出当天初步方案到 `records/17_initial/YYYY-MM-DD.md`。
- 21 点任务读取当天初步方案，并输出最终方案到 `records/21_final/YYYY-MM-DD.md`。
- 每日复盘任务读取预测、赛果和账本，输出复盘到 `records/reviews/YYYY-MM-DD.md`。
- 盲测回放写入 `records/blind_tests/YYYY-MM-DD-blind-replay.md`，用于隐藏赛果后验证模型和流程。

三个自动化都应优先读取本仓库内的规则、账本、历史记录和参数文件；无法可靠获取最新数据时必须明说，不补造数据。

## 投资自动化约定

- 策场/银狐凭据不得写入仓库，只能从本地安全配置读取。
- 每次盯盘必须记录：时间、账户状态、持仓、风险触发、交易动作、未执行原因。
- 冲排名策略可以满仓，但必须保留硬风控：单股上限、止损、止盈、回撤熔断。
- 投资模型的记录写入 `投资模型/records/`，不要写入竞彩 records。
